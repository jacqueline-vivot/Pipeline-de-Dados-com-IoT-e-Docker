# Base de dados

Fonte: Atul Anand Jha, [Temperature Readings: IoT Devices](https://www.kaggle.com/datasets/atulanandjha/temperature-readings-iot-devices).

Baixe `IOT-temp.csv` e salve nesta pasta, ou execute `python scripts/download_data.py` na raiz.
O CSV e os arquivos compactados não são versionados. Consulte os termos e a licença na página da fonte antes de redistribuir.

Colunas originais: `id`, `room_id/id`, `noted_date`, `temp`, `out/in`.
Datas usam dia-mês-ano. O campo `room_id/id` representa o identificador disponível do ambiente; não prova a existência de sensores físicos distintos.
